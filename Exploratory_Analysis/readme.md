# Exploratory Analysis Documentation

1. [summary.Rmd](https://github.com/Mohamed-Elmz/Fraud_Detection/blob/ME_2025/Exploratory_Analysis/summary.Rmd) is an R script that generates summary/ descriptive statistics of the Bank Account Fraud (BAF) Dataset. 
Numeric and categorical variables are summarized separately. The figures generated by summary.rmd are available in *Summary_Report.pdf*.

2. [discover.Rmd](https://github.com/Mohamed-Elmz/Fraud_Detection/blob/ME_2025/Exploratory_Analysis/discovery.Rmd) is an R script that examines the BAF's anonymized categorical variables. By implementing a Chi-Squared Test of Independence and Univariate Analysis, it uncovers the relationship each variable has to fraud. The figures generated by discover.Rmd are available in *Discovery_Report.pdf*.

3. [anomaly_detection.py](https://github.com/Mohamed-Elmz/Fraud_Detection/blob/ME_2025/Exploratory_Analysis/anomaly_detection.py) is a Python script that trains an Isolation Forest model to determine whether anomaly detection is sufficient for predicting fraud. The figures generated by anomaly_detection.py are available in *Anomaly_Report.pdf*.
